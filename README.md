# Autolog app shell

Static PWA front-end for [expense-autolog](https://github.com/wunwunzero/expense-autolog)
(private). Contains **no data and no secrets** — on first open you paste your dashboard
link; the backend address and view key are stored in `localStorage` on the device only.

- `?demo=1` renders sample data with no backend.
- The view key can read the snapshot and set a transaction's category — nothing else.
- Icons are generated by `node gen-icon.js` (no dependencies).

Hosted on GitHub Pages; add to the iPhone home screen for the full-screen app.
